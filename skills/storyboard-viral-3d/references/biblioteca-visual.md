# Biblioteca Visual — traduzir copy em imagem

Como transformar frases de copy em imagens fortes. Use como banco de ideias; sempre adapte ao personagem e nicho.

## Tradução de conceitos abstratos → imagem concreta

| Conceito na copy | Tradução visual |
|---|---|
| "cansaço / sem energia" | personagem curvado na mesa, fumaça/vapor saindo da cabeça, olhos pesados |
| "energia / disposição" | personagem com raios/brilho ao redor, pose de poder, cores quentes vibrantes |
| "inchaço / peso" | personagem segurando barriga inflada, ou bola/peso na frente do corpo |
| "toxinas / acúmulo" | personagem segurando bola gigante grotesca de resíduo, no pôr do sol pra contraste |
| "dentro do seu corpo" | CGI macro interno — microbioma brilhante, células, vasos sanguíneos |
| "limpeza / detox" | personagem com aspirador/escova limpando superfície suja → faixa limpa contrastando |
| "rápido / instantâneo" | speed ramp, partículas em movimento, transformação on-screen |
| "natural / da terra" | ingredientes reais (beterraba, raiz, fruta) flutuando, luz natural, verde |
| "antes e depois" | split visual ou duas versões do personagem lado a lado |
| "ciência / comprovado" | macro de célula/molécula, gráfico flutuando, ambiente clínico azul |

## Blocos de prompt reutilizáveis (colar no fim de cada prompt)

**Look técnico padrão (toda cena com personagem):**
```
cinematic composition, shallow depth of field, soft lighting with rim light, subsurface scattering on the translucent skin, soft shadows, global illumination, highly detailed PBR materials, 50mm lens, f/1.8, Octane render style, ultra detailed, photorealistic lighting, 4K, vertical 9:16 format
```

**Cena de mecanismo (CGI interno, sem personagem):**
```
hyper-detailed macro 3D render of the human [microbiome/bloodstream/neurons], glowing colorful bacteria and particles, soft bokeh, wet glossy organic surfaces, subsurface scattering, volumetric light rays, shallow depth of field, scientific yet beautiful, cinematic, 4K, vertical 9:16 format
```

**Cena de produto / CTA (mão real, sem personagem):**
```
a real human hand holding a [product bottle/package] close to camera, simple lifestyle background softly blurred, natural daylight, UGC smartphone photo aesthetic, authentic and unpolished, slight motion, big red arrow graphic pointing at the product, vertical 9:16 format
```

## Expressões do personagem (escolher por beat)

- Hook → olhos arregalados, choque cômico, boca aberta
- Problema → exausto, sobrancelha caída, derrotado
- Mecanismo → (personagem fora de cena)
- Vilão → nojo/horror cômico encarando o objeto
- Prova → sorriso confiante, pose de vitória, energia
- CTA → (mão real)

## Cenários por contraste (churn)

Alterne ambientes pra manter novidade. Sequência que funciona bem:
academia azul → quarto/cotidiano → CGI interno do corpo → praia/pôr do sol surreal → escritório → close de produto real.

A troca brusca de cenário ENTRE personagem consistente é o efeito-assinatura do formato.
